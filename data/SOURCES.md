# Источники данных

## Официальный источник

**Издатель:** Федеральная служба государственной статистики (Росстат)  
**Публикация:** Приложение к сборнику «Регионы России. Социально-экономические показатели»  
**Название файла на сайте:** «Социально-экономические показатели по субъектам Российской Федерации»  
**Выпуск:** 2025 (опубликован 30.12.2025)  
**Формат:** архив RAR (8,86 МБ) с таблицами XLSX по 20 разделам

- Страница публикации: https://rosstat.gov.ru/folder/210/document/47652
- Прямая ссылка на архив: https://rosstat.gov.ru/storage/mediabank/Pril_Region_Pokaz_2025.rar
- Страница самого сборника «Регионы России. Социально-экономические показатели»: https://rosstat.gov.ru/folder/210/document/13204

Ссылки проверены 12.10.2026. Файлы в `data/raw` — содержимое архива `Pril_Region_Pokaz_2025.rar` без изменений.

**Как ссылаться:**
Регионы России. Социально-экономические показатели. 2025: приложение к статистическому сборнику [Электронный ресурс] / Росстат. — М., 2025. — URL: https://rosstat.gov.ru/folder/210/document/47652 (дата обращения: 12.10.2026).
