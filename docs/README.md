## С чего начать

- **Хочу прочитать исследование** → [`results/REPORT.md`](../results/REPORT.md).
- **Хочу пересчитать всё сам** → [USAGE.md](USAGE.md), раздел «Быстрый старт».
- **Хочу взять готовые данные** → [`data/processed/panel.csv`](../data/processed/panel.csv) и описание столбцов в [DATA.md](DATA.md).
- **Хочу добавить показатель или модель** → [USAGE.md](USAGE.md), раздел «Типовые задачи».
- **Хочу понять, откуда взялось число в отчёте** → [RESULTS.md](RESULTS.md): у каждой таблицы указана функция, которая её считает.

## Принципы проекта

1. **Воспроизводимость.** В репозитории нет ни одного числа или графика, внесённого вручную. Отчёт, таблицы и рисунки создаёт команда `python -m regions` из файлов `data/raw`.
2. **Исходные данные не изменяются.** Файлы Росстата лежат в том виде, в каком опубликованы; вся очистка — в коде.
3. **Один источник правды для показателей.** Что и откуда читать, задано списком в `regions/indicators.py`.
4. **Текст отчёта привязан к расчётам.** Числа в трактовках подставляются из результатов, поэтому при изменении данных текст не расходится с таблицами.
