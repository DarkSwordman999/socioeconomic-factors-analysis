# Использование

## Быстрый старт

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/DarkSwordman999/socioeconomic-factors-analysis.git
cd socioeconomic-factors-analysis

python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt

python -m regions
```

Расчёт занимает около минуты и проходит шесть шагов:

| Шаг | Что делает | Что создаёт |
|---|---|---|
| 1/6 | читает `data/raw`, собирает панель, пересчитывает цены | `data/processed/panel.csv`, `russia.csv` |
| 2/6 | разведочный анализ, корреляции, парные и множественные регрессии, сходимость | — |
| 3/6 | панельные модели | `results/tables/coefficients.csv` и др. |
| 4/6 | кластеризация, тесты панельных моделей, проверка устойчивости | `results/tables/clusters.csv` и др. |
| 5/6 | графики | `results/figures/*.png` |
| 6/6 | текст исследования и остальные таблицы | `results/REPORT.md`, `results/tables/*.csv` |

Всё в `data/processed` и `results` перезаписывается. Результат детерминирован: генератор случайных чисел в кластеризации зафиксирован.

## Интерактивная панель

```bash
streamlit run app.py
```

Откроется страница в браузере с четырьмя вкладками:

| Вкладка | Возможности |
|---|---|
| Регион | динамика любого показателя для выбранных регионов на фоне медианного региона и России в целом |
| Связь показателей | диаграмма рассеяния двух показателей за выбранный год, цвет — федеральный округ, коэффициент Спирмена |
| Рейтинг | все регионы по выбранному показателю и году |
| Типология | кластеры на плоскости главных компонент и состав каждого кластера |

Панель читает `data/processed/panel.csv`; если файла нет, она соберёт его сама.

## Тесты

```bash
pytest
```

Проверяется очистка названий, состав панели (82 региона, нет агрегатов и дублей), совпадение значений с исходными таблицами, дефлятор, знак и значимость ключевого коэффициента, корректность кластеров и расчётов для отчёта.

## Использование как библиотеки

```python
from regions.dataset import build_panel, load_panel
from regions.models import fit_spec
from regions import analysis

panel = load_panel()                                   # готовая панель из CSV
panel, russia = build_panel()                          # или собрать заново из data/raw

model, sample, r2_within = fit_spec(panel, "poverty", "fe_controls")
print(model.params["ln_income"], r2_within)

pairs, curves = analysis.pair_models(panel, year=2023) # парные регрессии пяти форм
table, points = analysis.beta_convergence(panel, 2000, 2023)
```

Справочник функций — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Типовые задачи

### Добавить показатель из сборника

1. Найдите нужную таблицу: откройте файл раздела в `data/raw`, первый лист — оглавление с номерами таблиц.
2. Добавьте строку в `INDICATORS` в `regions/indicators.py`:

   ```python
   Indicator("wage", 3, "3.4.", "Среднемесячная зарплата", "руб.", money=True),
   ```

   Поля: имя столбца, номер раздела, название листа, название показателя, единица. `money=True` — показатель в рублях, для него появится столбец `wage_real` в ценах 2023 года.
3. Запустите `python -m regions` — столбец появится в `panel.csv`.

Таблица должна иметь стандартный вид «регионы по строкам, годы по столбцам». Листы с несколькими таблицами подряд читаются до первой строки сносок.

### Использовать показатель в моделях

- как контрольную переменную — добавьте имя в `CONTROLS` в `regions/indicators.py`;
- как зависимую — в `TARGETS` (и подпись в `SHORT_TARGETS` в `regions/plots.py`, `NAMES` и `GENITIVE` в `regions/report.py`);
- в типологии регионов — в `FEATURES` в `regions/clusters.py`.

### Добавить спецификацию панельной модели

В `regions/models.py` дополните словарь `SPECS`:

```python
"fe_region_only": {
    "title": "Только эффекты региона",
    "logs": ["gdp_real", "invest_real", "income_real"],
    "extra": ["C(region)"],
},
```

`logs` — факторы, которые логарифмируются; `extra` — всё остальное в правой части в синтаксисе формул statsmodels. Новая модель автоматически попадёт в `coefficients.csv` и в таблицы оценок раздела 8.4 отчёта.

### Обновить данные следующим выпуском

1. Замените файлы в `data/raw` файлами нового архива Росстата (имена вида `Раздел N - ….xlsx`).
2. Поправьте `LAST_YEAR` и при необходимости `BASE_YEAR` в `regions/dataset.py`.
3. Запустите `python -m regions` и `pytest`. Если Росстат изменил номера листов, тесты или загрузчик сообщат, какой таблицы не хватает; номера листов задаются в `regions/indicators.py`.
4. Обновите ссылки в `data/SOURCES.md`.

Текст отчёта пересоберётся с новыми числами. Утверждения, не зависящие от чисел напрямую (например, объяснения причин), стоит перечитать.

### Изменить число кластеров

Константа `N_CLUSTERS` в `regions/clusters.py`. Трактовка кластеров в разделе 9.4 отчёта написана для трёх.

## Возможные ошибки

| Сообщение | Причина и решение |
|---|---|
| `FileNotFoundError: нет файла раздела N` | в `data/raw` нет файла `Раздел N - ….xlsx` — проверьте, что репозиторий склонирован полностью |
| `ValueError: не найдена строка с годами` | на листе нет строки с годами в заголовке — таблица нестандартного вида, см. [DATA.md](DATA.md) |
| `Worksheet named '…' not found` | в `indicators.py` указан неверный лист; названия листов заканчиваются точкой (`"3.2."`), но не все |
| `ModuleNotFoundError: No module named 'regions'` | команда запущена не из корня репозитория |
| Кракозябры в консоли Windows | задайте `set PYTHONIOENCODING=utf-8` перед запуском |
