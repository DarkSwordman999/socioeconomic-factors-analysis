# Устройство кода

## Поток данных

```
data/raw/*.xlsx
      │  loader.read_indicator          чтение листа, очистка названий, тип строки
      ▼
dataset.build_panel                     объединение показателей, индекс цен, реальные величины
      │
      ├──► data/processed/panel.csv, russia.csv
      ▼
┌──────────────────┬───────────────────┬────────────────────┐
│ analysis         │ models            │ clusters           │
│ распределения    │ панельные модели  │ k-средних          │
│ корреляции       │ четырёх           │ главные компоненты │
│ парные регрессии │ спецификаций      │                    │
│ срезы, тесты     │                   │                    │
│ сходимость       │                   │                    │
└────────┬─────────┴─────────┬─────────┴──────────┬─────────┘
         └───────────────────┼────────────────────┘
                             ▼
              plots.plot_all ──► results/figures/*.png
              report.build_report ──► results/REPORT.md, results/tables/*.csv
```

Порядок шагов задаёт `regions/__main__.py`. Модули расчётов не зависят от графиков и отчёта, поэтому ими можно пользоваться отдельно.

## Модули

### `regions/indicators.py`

Описание показателей — единственное место, где указано, что и откуда читать.

| Имя | Что это |
|---|---|
| `Indicator` | запись: `key`, `section`, `sheet`, `title`, `unit`, `money` |
| `INDICATORS` | список всех показателей |
| `MONEY` | показатели в рублях, для которых считаются реальные величины |
| `FACTORS`, `TARGETS`, `CONTROLS` | роли переменных в моделях |
| `LABELS`, `UNITS` | подписи и единицы для графиков и таблиц |

### `regions/loader.py`

| Функция | Назначение |
|---|---|
| `read_indicator(ind, raw_dir)` | лист XLSX → таблица `name, kind, district, year, value` |
| `clean_name(value)` | единый вид названия территории |
| `kind_of(name)` | тип строки: `country`, `district`, `part`, `region` |

Алгоритм чтения описан в [DATA.md](DATA.md).

### `regions/dataset.py`

| Функция | Назначение |
|---|---|
| `build_panel(raw_dir)` | собирает панель регионов и ряд по России, добавляет `price_index` и `*_real` |
| `save_panel(regions, russia)` | пишет CSV в `data/processed` |
| `load_panel()`, `load_russia()` | читают готовые CSV |

Константы: `FIRST_YEAR`, `LAST_YEAR` — границы периода; `BASE_YEAR` — год, в ценах которого выражены реальные величины.

### `regions/analysis.py`

Статистические процедуры исследования. Каждая функция принимает панель и возвращает таблицу.

| Функция | Что считает | Раздел отчёта |
|---|---|---|
| `normality(panel, year, columns)` | критерий Шапиро — Уилка в уровнях и логарифмах | 3.2 |
| `extremes(panel, year, column)` | регионы с наибольшими и наименьшими значениями | 3.4 |
| `sigma_convergence(panel)` | коэффициент вариации между регионами по годам | 4.1 |
| `beta_convergence(panel, first, last)` | регрессия темпа роста на исходный уровень, скорость сходимости | 4.2 |
| `corr_tests(panel, year)` | коэффициенты Пирсона (с интервалом по Фишеру), Спирмена и Кендалла | 5.2 |
| `partial_corr(panel, year)` | частные корреляции при фиксированных остальных факторах | 5.3 |
| `kendall_w(frame)`, `concordance(panel, year)` | коэффициент конкордации Кендалла | 5.4 |
| `pair_models(panel, year)` | парные регрессии пяти форм, R², F, ошибка аппроксимации, эластичность | 6 |
| `cross_section(panel, year)` | множественная регрессия на срезе, β*, VIF, тесты Бройша — Пагана, Харке — Бера, RESET | 7.2 |
| `yearly_coefficients(panel)` | та же регрессия по каждому году | 7.4 |
| `panel_tests(panel)` | F-тест фиксированных эффектов, гетероскедастичность, автокорреляция остатков | 8.3 |
| `mundlak_test(panel)` | тест Мундлака: фиксированные или случайные эффекты | 8.3 |
| `structural_break(panel, break_year)` | F-тест на различие коэффициентов до и после 2012 года | 8.3 |
| `partial_regression(panel, target)` | остатки для частного графика регрессии | 8.5 |
| `poverty_elasticity(panel)` | панельная модель с логарифмом бедности | 8.6 |
| `robustness(panel, leaders)` | коэффициент при доходах на разных выборках и в первых разностях | 8.7 |
| `cluster_diagnostics(panel, year, assignments)` | инерция по k, нагрузки главных компонент, критерий Краскела — Уоллиса | 9 |

### `regions/models.py`

Панельные модели. Оцениваются МНК с фиктивными переменными регионов и лет, что эквивалентно внутригрупповому преобразованию; стандартные ошибки кластеризованы по регионам.

| Имя | Назначение |
|---|---|
| `SPECS` | четыре спецификации: `naive`, `real`, `fe`, `fe_controls` |
| `fit_spec(panel, target, spec_name)` | одна модель → `(результат statsmodels, выборка, внутригрупповой R²)` |
| `run_models(panel)` | все модели → таблица коэффициентов и сводка качества |
| `effect_of_10pct(coefs)` | коэффициенты при логарифмах → эффект роста фактора на 10 % |
| `vif_table(panel)` | коэффициенты вздутия дисперсии |

Внутригрупповой R² считается как `1 − SSR(модель) / SSR(только эффекты)` на той же выборке.

### `regions/clusters.py`

| Имя | Назначение |
|---|---|
| `FEATURES` | девять показателей типологии |
| `N_CLUSTERS`, `SEED` | число кластеров и зерно генератора |
| `cluster_regions(panel, year, k)` | → `(регионы с кластером и координатами ГК, профили кластеров, силуэт по k)` |

Кластеры нумеруются по убыванию среднего реального дохода, поэтому номер не меняется от запуска к запуску.

### `regions/plots.py`

По функции на рисунок; все сохраняют PNG в `results/figures` и возвращают путь. `plot_all` вызывает их по порядку. Общий стиль (палитра, сетка, шрифты) задан в начале модуля через `plt.rcParams`. Что изображено на каждом рисунке — в [RESULTS.md](RESULTS.md).

### `regions/report.py`

Собирает `results/REPORT.md`. Каждый раздел — функция, возвращающая Markdown: формулы хранятся в строковых константах (`_CORR`, `_PAIR`, `_PANEL` …), а таблицы и числа в трактовках подставляются из результатов. `build_report(results)` принимает словарь, который формирует `__main__.py`, и заодно сохраняет таблицы в `results/tables`.

Вспомогательные функции: `_num`, `_p`, `_pt` — форматирование чисел и p-значений; `_table` — таблица Markdown; `_strength` — словесная оценка тесноты связи по шкале Чеддока; `_equation` — запись уравнения парной регрессии.

### `app.py`

Панель на Streamlit и Plotly. Читает `panel.csv`, кластеры считает через `cluster_regions`. Данные кэшируются декоратором `st.cache_data`.

### `tests/test_pipeline.py`

Панель собирается один раз на модуль (фикстура `data`), тесты проверяют загрузчик, состав панели, совпадение со значениями в исходных таблицах, дефлятор, модели, кластеры и расчёты отчёта.

## Соглашения

- Имена столбцов и идентификаторы — латиницей, подписи, комментарии и документация — на русском.
- Логарифмы факторов в моделях называются `ln_gdp`, `ln_invest`, `ln_income` независимо от того, номинальные они или реальные; какие именно — определяет спецификация.
- Функции расчётов не пишут на диск: сохранением занимаются `__main__.py` и `report.py`.
- Уровень значимости в текстах — 5 %; в таблицах коэффициентов `***`, `**`, `*` — 1, 5 и 10 %.
